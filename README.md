# Домашнее задание по SQL и DBeaver

## Описание проекта

В рамках домашнего задания выполнена работа с базой данных SQLite в программе DBeaver.

## Таблицы базы данных

- **Orders** — хранит информацию о заказах.
- **products** — содержит информацию о товарах: артикул, название, описание, категорию и цену.

## Связи между таблицами

Таблицы связаны внешним ключом `Product_ID`, который ссылается на поле `id` таблицы `products`.

Связь позволяет сопоставлять заказы с соответствующими товарами.

## Выполненные задания

- Создание и изучение структуры таблиц.
- Настройка внешнего ключа между таблицами.
- Работа с SQL-запросами.
- Объединение таблиц с помощью `JOIN`.
- Получение информации о заказах и товарах.
